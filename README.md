### Django Todo App

A simple and efficient task management application built with Django Class-Based Views.

## Features
- Task Management: Create, update, view, and delete tasks with ease.

- Tag System: Organize your tasks using customizable tags.

- Status Toggle: Quick one-click status switching (Done / Not Done) without forms.

## Quick Start

``` shell
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

``` shell
python manage.py migrate
```

``` shell
python manage.py runserver
```

main website page - http://127.0.0.1:8000
